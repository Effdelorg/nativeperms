## 0.1.0

* Initial release of `nativeprems`.
* Adds permission status checks, permission requests, service status checks, and app settings helpers.
* Supports Android, iOS, web, and Windows plugin registrations.
* Uses `package:nativeprems/nativeprems.dart` as the public import path.
* Uses `dev.effdel.nativeprems/methods` as the native method channel. Rebuild app and plugin artifacts together when upgrading from older local package names.
